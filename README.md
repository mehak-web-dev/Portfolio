# Mehak Batool — Professional Portfolio 🚀

A modern, high-performance developer portfolio built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**, optimized for instant deployment on **Vercel**.

Designed for **Mehak Batool**, Web Developer at **NextGen Arts** and Software Engineering student at **Karakoram International University Gilgit (KIU)**.

---

## ✨ Features

- **Fluid Animations & Micro-Interactions**: Powered by Framer Motion, featuring smooth reveal-on-scroll, hover elevation, and pulsing ambient glows.
- **Interactive Constellation Canvas**: Dynamic particle constellation in the hero background with mouse-tracking attraction.
- **Glassmorphic Design**: Modern cyber-aesthetic with frosted glass panels, subtle border glows, and typography powered by *Plus Jakarta Sans*.
- **Comprehensive Resume / CV Modal**: Clean curriculum vitae viewer with print/save-to-PDF functionality and celebratory confetti bursts.
- **Curated Projects Showcase**: Category filters (*NextGen Arts*, *Web Apps*, *UI/UX Design*) and deep-dive modals with feature breakdown and tech stacks.
- **Interactive Experience & Education Timeline**: Dedicated highlights for NextGen Arts and KIU BS Software Engineering.
- **Contact & WhatsApp Integration**: Form validation, direct WhatsApp chat, and one-click clipboard copying for email and phone numbers.
- **100% Mobile Responsive**: Seamless experience on smartphones, tablets, laptops, and ultra-wide screens.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion & Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Vector Brand SVGs
- **Celebration Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Deployment**: [Vercel](https://vercel.com/) (Pre-configured `vercel.json`)

## 🚀 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
Production assets are generated in the `dist/` directory.

---

## 🌐 Deploying to Vercel

### Method 1: Using the Vercel CLI (Fastest)
1. Run:
   ```bash
   npx vercel
   ```
2. Follow the on-screen prompts (accept default settings).
3. For production deployment:
   ```bash
   npx vercel --prod
   ```

### Method 2: Via GitHub & Vercel Dashboard
1. Initialize git and push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Mehak Batool portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio-of-mehak.git
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository.
4. Framework preset will automatically detect **Vite** with build command `npm run build` and output directory `dist`.
5. Click **Deploy**!
